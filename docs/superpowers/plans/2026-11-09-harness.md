# Wandora Harness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Next.js + TypeScript repo where lint, format, typecheck and tests each run with one documented command, locally and in CI, plus the rules file, assistant permissions and secret hygiene for PA#2 criteria 1–3 and the CI half of 4.

**Architecture:** One Next.js App Router app. Four npm scripts are the single source of truth for checks; the README documents them and five CI jobs call them verbatim (plus gitleaks). Backend-only code lives in `src/server`.

**Tech Stack:** Next.js (App Router), TypeScript, npm, ESLint (Next config), Prettier, Vitest, GitHub Actions, gitleaks.

**Spec:** `docs/superpowers/specs/2026-11-09-harness-design.md`

## Global Constraints

- Node 24; npm with committed `package-lock.json`; CI installs with `npm ci`.
- Check commands, exactly: `npm run lint`, `npm run format:check`, `npm run typecheck`, `npm test`, `npm run check`.
- No CI step may hide a failure: no `|| true`, no `continue-on-error`, no `--passWithNoTests`.
- CI triggers: `pull_request`, `push` to `main`, `push` of tags.
- Env vars: `DATABASE_URL`, `GEMINI_API_KEY`, `GEMINI_MODEL`; no `NEXT_PUBLIC_` key variable.
- No commit without the user's explicit approval (user rule); never push to `main` once protection is on.

## Review Focus

1. A check that passes when it should fail (empty test set, a lint config that ignores `src/`): each job is forced red once in Task 3.
2. Prettier vs ESLint disagreeing so `check` can never be green: Task 1 runs `npm run check` on the fresh scaffold.
3. Prettier rewriting generated or vendored files (`.next/`, lockfile) and failing `format:check`: Task 1 adds `.prettierignore`.
4. Line endings on Windows making `format:check` red in CI but green locally: Task 1 sets `.gitattributes` `* text=auto eol=lf` and Prettier `endOfLine: "lf"`.
5. `.env` with a real key slipping into a commit: Task 2 `.gitignore` + gitleaks job in Task 3.
